# Wordle po polsku

## 1. Nazwa projektu/aplikacji
Wordle po polsku

## 2. Pomysł i krótki opis aplikacji
Webowa gra słowna Wordle wzbogacona o możliwość dostosowywania i łączenia wielu poziomów trudności, użytkownik może swobodnie mieszać ze sobą następujące tryby:
1. Wybranie długości odgadywanego słowa,
2. Ukryta podpowiedź - losowo wybrana litera z wpisanego słowa nie generuje żadnego feedbacku,
3. Zakres widoczności - widoczna jest tylko ostatnio wpisana próba z jej wynikami,
4. Odwrócona logika - losowa zamiana znaczenia podpowiedzi wizualnych. Na przykład: zielony oznacza brak litery, zółty właściwą literę na właściwej pozycji, a szary, że litera jest właściwa, ale na innej pozycji,
5. Timer - regulowany czas na wprowadzenie pojedynczej próby, przekroczenie limitu skutkuje utratą próby.

Dodatkowo gra oferuje: 
1. System logowania i rejestracji użytkowników,
2. Statystyki rozegranych partii dla każdego użytkownika, 
3. Rankingi graczy z największą liczbą gier oraz największą liczbą wygranych gier,
4. Licznik graczy zalogowanych w czasie rzeczywistym.
